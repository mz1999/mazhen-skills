# 技术分析：从指标本质到走势解读

## 任务边界

只使用价格、成交量和时间信息分析走势。默认交付「走势状态解释 + 关键观察区域 + 条件情境推演」，不从指标直接推出买入、加仓或卖出指令。用户提供交易周期、持仓状态和风险约束时，可另设执行讨论。

报告面向没有技术分析背景、但具备逻辑判断能力的读者。首次出现的术语必须解释；类比必须符合指标的数学含义及其假设。

## 核心原则

- **原料先于加工**：先描述原始价量，再用指标帮助观察。指标是历史数据的变换，不是行情变化的原因。
- **测量先于解释**：依次区分「原始观察 → 数学加工 → 直接测量 → 市场行为解释 → 条件推演」。公式只能直接支持前三层。
- **信号按信息合并**：均线、MACD、DMI 等同向变化可能只是在重复描述价格趋势，不能当作多份独立证据。
- **通俗且准确**：均线是历史收盘价的平均值，不是现实持股者的真实成本；成交量是成交活跃程度，不是净买盘。
- **允许暂不判断**：信息不足或信号冲突时，明确当前能确认什么、不能确认什么。
- **概率需要依据**：没有历史统计或回测支持时，使用条件推演，不写「大概率」「高胜率」或综合评分。

## 分析流程

### 第一步：确定时间级别与数据口径

1. 确认标的和主时间级别。默认以周线提供背景、日线作为主分析级别；用户要求短线分析时，再加入更小级别。
2. 获取主级别至少 60 个周期的开、高、低、收、成交量，以及可得的背景级别数据。
3. 记录数据来源、截至时间、复权方式和指标参数。盘中数据必须标注当前 K 线尚未完成。
4. 核对字段和日期连续性，基于同一快照计算指标。缺失的背景级别或指标数据应列为分析边界，只分析现有数据能够支持的内容。

**完成标准**：每个数值都能追溯到同一时点的数据，每项结论都标明所属时间级别。

### 第二步：先写原始价量观察

先不使用指标名称，完成以下观察：

- 高点与低点如何演化，价格中枢向哪个方向移动。
- 当前涨跌幅、收盘或现价在当日区间的位置。
- 成交量相对可比基准如何变化，价格随后作出什么反应。
- 哪些历史区域值得继续观察。支撑与压力使用区域表达，并说明其只是行为假设。

**完成标准**：能够只用原始价量数据写出一段走势摘要，后续指标用于补充而非替代这段摘要。

### 第三步：按五维选择最少的工具

每个维度默认使用「原始价量证据 + 一个主要加工工具」。第二个指标只有提供不同信息并说明增量时才加入。

| 维度 | 直接测量的问题 | 默认证据与工具 | 解释边界 |
|------|----------------|----------------|----------|
| 趋势结构 | 价格变化的方向与持续性 | 高低点结构、均线方向 | 均线数量多不代表独立证据多 |
| 动能强弱 | 价格变化的速度及其变化 | MACD | 动能不是可观测的真实资金力量 |
| 关键位置 | 当前价格相对历史价格的位置 | 历史高低点、乖离率 | 偏离均线不自动等于低估或反转 |
| 量价配合 | 成交活跃程度与价格反应 | 相对成交量或量比 | 成交量不区分净买方或净卖方 |
| 波动性 | 价格变化的幅度 | ATR | 波动幅度不指示方向，也不等于全部投资风险 |

RSI、KDJ、DMI、BOLL 等仅在能回答额外问题时使用。不要为了填齐维度而增加指标。

**完成标准**：每个入选指标都能回答「它提供了什么原始价量或其他入选指标没有直接呈现的信息」。

### 第四步：逐项翻译指标

正文中的每个指标都按以下顺序解释，详细计算过程和完整数值可放附录：

1. **一句话本质**：它直接测量什么。
2. **最简公式**：保留理解所需的变量、周期和参数。
3. **当前怎么读**：数值对这个标的、这个时间级别意味着什么。
4. **不能说明什么**：指出最可能发生的误读。
5. **怎样验证**：后续什么变化会增强或削弱当前解释。

使用成本、买卖力量、支撑压力等类比时，先写明假设。若类比会扩大指标含义，改用直接描述。

**完成标准**：读者不看其他材料，也能复述指标如何由原始数据得到，以及当前结论为什么只是解释而非确定预测。

### 第五步：合并证据并推演

1. 将重复描述同一价格现象的信号合并，再列出真正不同的观察。
2. 分别陈述各时间级别，不把「周线下降、日线反弹」写成含糊的多空矛盾。
3. 使用「延续、转强、转弱」或适合当前状态的情境。每种情境都写观察条件、解释和失效条件。
4. 信号不足时输出「暂不足以形成方向判断」，并指出缺少什么证据。
5. 默认不输出综合分数、预期收益率或交易指令。

**完成标准**：每个方向性表述都有可观察条件，每个当前解释都有失效条件，且未把条件推演写成统计概率。

## 核心指标解释基准

### 均线（MA）

`MA(N) = 最近 N 个周期收盘价之和 ÷ N`

均线测量历史收盘价格的平均中枢；均线方向比较本期与上期均值，观察中枢如何移动。只有在「每个周期以收盘价买入相同数量且一直持有」的假想条件下，才能把它近似解释为这批买入者的平均成本。它不包含真实成交量、换手和当前持仓结构，也不天然构成支撑或压力。

### 指数平滑异同移动平均线（MACD）

`DIF = EMA(12) − EMA(26)`，`DEA = DIF 的 9 周期 EMA`

MACD 观察快慢两条指数均线之间的距离及其变化。DIF 小于零表示快均线低于慢均线；DIF 与 DEA 的关系描述这种差距的近期变化。柱体可能使用 `DIF − DEA` 或其 2 倍，必须与数据源的口径一致。MACD 不直接测量资金流入，也不单独证明未来方向。

### 乖离率（BIAS）

`BIAS(N) =（当前价格 − MA(N)）÷ MA(N) × 100%`

乖离率测量当前价格相对过去 N 个周期平均收盘水平的偏离程度。正值表示高于该均值，负值表示低于该均值。它不等于现实投资者的整体盈亏，也不单独意味着价格必然回归均线。

### 量比与相对成交量

常见量比口径为「截至当前的每分钟平均成交量 ÷ 过去 5 日每分钟平均成交量」，具体以数据源定义为准。相对成交量必须采用可比时段；盘中累计成交量不能直接与历史全天成交量比较。

这些指标测量交易活跃程度。每笔成交同时存在买方和卖方，因此活跃程度不等于净买盘；还要结合随后价格反应解读。开盘初期和收盘前的数值可能受到交易时段结构影响。

### 平均真实波幅（ATR）

`TR = max（最高价 − 最低价，|最高价 − 昨收|，|最低价 − 昨收|）`

ATR 是 TR 的平均值，常用 14 周期，并需注明简单平均或 Wilder 平滑口径。它测量价格通常在一个周期内覆盖多大范围，具有价格单位；需要横向或跨标的比较时，可另用 `ATR ÷ 当前价格`。ATR 不指示涨跌方向。

## 输出结构

按以下顺序组织报告：

1. **一句话状态**：不用指标术语概括当前走势。
2. **数据范围与原始走势**：时间级别、数据时点、高低点结构、价格与成交观察。
3. **五维解读**：每维写「测量对象 → 最简公式 → 当前含义 → 误读边界 → 验证条件」。
4. **证据合并**：指出重复信号、增量信息和级别差异。
5. **条件推演**：列出各情境的观察条件、解释与失效条件。
6. **观察清单**：只保留后续需要跟踪的少数变量。
7. **分析边界**：盘中状态、缺失数据、指标口径和其他限制。

## 最终检查

- 原始价量观察是否先于指标结论。
- 每个指标是否完整解释测量对象、公式、当前含义、局限和验证条件。
- 所有周期、参数、来源、时点及盘中状态是否明确。
- 类比是否保留必要假设，是否把均线成本、净买盘或支撑压力说成了未经验证的事实。
- 重复信号是否合并，无依据的评分和概率是否缺席。
- 是否允许信息不足，并为当前解释给出失效条件。
- 报告是否保持纯技术分析，且未从指标直接推出交易指令。
