# 技术分析框架(体检版)

对任意标的做量价体检,只回答三个问题——① 中线趋势如何?② 短线有没有异常?③ 短线适不适合下手?

> 约定(中国习惯):**红 = 涨,绿 = 跌**。本框架为量价观察工具,**非投资建议**。

**三条原则(分析全程遵守)**
1. 指标只用于定义位置与纪律,**不做方向预测**;指标彼此相关且滞后,不堆砌多重确认。
2. 确认与赔率此消彼长:不等"所有指标都走好",**位置比信号清晰度重要**。
3. **认知判断从粗**(只打"正常 / 注意 / 异常"三档),**纪律规则从细**(赔率、仓位、止损必须照算照执行,不打折)。

## 何时使用

对一个标的代码(可附当前量价数据)做技术面体检时调用——典型如"用本框架给 [代码] 做体检""给 XXX 股/ETF 做个体检""分析下 [代码] 现在能不能买"。

## 工作流程

1. **收集数据。** 行情数据 Agent 无法自行实时获取,需要用户提供(或用户用行情软件取数后给出)。体检所需的输入:
   - **周线**:均线排列与斜率、`(P−MA60)/MA60` 所处自身一年的分位。
   - **日线**:`RSI(14)` 当前值及其自身一年分位、成交量价关系(价涨量增 / 价涨量缩 / 放量下跌)、是否有顶背离 / 量价背离 / **消息钝化**(利好不涨、利空大跌)。
   - **算纪律账所需**:现价 / 拟入场价、止损位(关键支撑如平台下沿 / MA20、`ATR(14)`)、前高、布林上轨(`BOLL(20,2)`)。
   数据不全时,把缺失项作为报告中的"待补"标出。
   *Done:* 周线/日线/纪律账三类数据齐备,或缺失项已在报告中标"待补"。

2. **走三问流程。** 按第一问 → 第二问 → 第三问顺序判断;**空头市直接判"不接刀"并终止**。
   *Done:* 中线档位(多头/震荡/空头)、短线各项(动量/量能/背离)、赔率 R 全部得出。

3. **查行动对照表**得出唯一判决(以第 4 节为唯一判决出口)。
   *Done:* 从行动对照表锁定唯一动作。

4. **输出体检报告**,严格按第 5 节模板。
   *Done:* 报告严格符合第 5 节模板。

## 1. 第一问:中线趋势如何?(看周线)

| 检查 | 正常 | 注意 | 异常 |
|------|------|------|------|
| **周线趋势**(均线排列+斜率) | 多头排列、斜率向上 | 走平缠绕(= 震荡市) | 空头压头(= 空头市) |
| **位置** | 早期:刚起涨 / 刚突破 | 中段:已涨一段,但未透支 | 末端:(P−MA60)/MA60 处自身一年 ≥95% 分位 |

- 结论三档:**多头 / 震荡 / 空头**。
- 多头且位置非末端 → 进第二问;**空头 → 直接判"不接刀"**,流程结束;**震荡 → 换均值回归思路**(超买卖、超卖买),不追"全绿"。

## 2. 第二问:短线有没有病?(看日线)

| 检查 | 正常 | 注意(= 有病) |
|------|------|----------------|
| **动量** | RSI(14) 未超买 | RSI 处自身一年 **≥95% 分位**(超买) |
| **量能** | 价涨量增 | 价涨量缩 / 放量下跌 |
| **背离** | 无 | 顶背离 / 量价背离 / **消息钝化**(利好不涨、利空大跌,含金量最高) |

- 全部正常 → 短线可跟;任一项"注意" → 进第三问按病给药。
- **A 股校正**:涨跌停日的 RSI 会机械性极端,须人工校正,不机械触发。

## 3. 第三问:适不适合下手?(算纪律账)

- **赔率**:R =(目标 − 入场)÷(入场 − 止损);**目标价 = min(前高, 量度涨幅, 布林上轨)**,取三者最保守,不许拍脑袋编目标。**R ≥ 2 才出手**;R < 2 → 不追,等回踩改善赔率,或仅以 ≤2% 市值试探。
- **仓位**:实际仓位 = **min(本金 × 1% ÷(入场 − 止损), 单笔市值 ≤5%, 组合同向暴露 ≤20%)**。三重上限是叠加约束。
- **止损**:结构位(平台下沿 / MA20 等)下浮约 1×ATR(14)。跌停、跳空不保证成交,缓冲即为此设。

## 4. 行动对照表(唯一判决出口)

| 体检结果 | 动作 |
|----------|------|
| 中线多头 + 位置早期/中段 + 短线无异常 | **可跟 / 持有**,移动止盈(跌破短期均线走),不猜顶 |
| 单层超买(无背离) | **不追**;持仓者停止加仓 + 收紧止损,**不减仓**(强趋势中超买可挂数周,单层超买就减仓 = 猜顶) |
| 超买 + 背离 | **减仓**(如减半) |
| 放量跌破关键支撑 | **清仓 / 大幅减** |
| 空头市 | **不接刀**;等重新站回 MA60 且放量(右侧信号)再谈 |
| 震荡市 | 均值回归,超买卖超卖买;**不谈"跟"** |

## 5. 输出格式:体检报告模板

输出铁律:**第一行永远是大白话结论**——只许用日常语言,回答三件事:大方向好不好?现在能不能买?已持有的怎么办、盯哪个数?体检行白话在前、术语在括号(保证日志口径统一、可复盘)。

```
标的/日期:____
【大白话结论】____(2~4 句,不许堆术语)
【体检行】
大方向(周线):上涨中(多头)·下跌中(空头)·横盘(震荡);阶段:刚起步(早期)·走到一半(中段)·正在回调·涨太多了(末端)
位置(价格离均线远不远):低位区·不高·偏高·透支
劲头(动量):正常·涨过头(超买)
买气(量能):正常·价涨量缩·放量下跌
异常信号(背离):无·有(价格新高指标没跟上 / 利好不涨利空大跌)
【结论分两行】新资金:____ | 持仓者:____
【若下手】买入价__ 止损价(跌到这就认错离场)__ 目标价__ 赔率 R=__(可能赚的÷可能亏的,≥2 才合格) 仓位≤__%
20 日后回填:走势____ 判定对否____
```

填写示例(供对齐输出风格):

```
标的/日期:2026-08-13 / 159819 人工智能ETF(收盘 1.828)
【大白话结论】大方向还是上涨,现在这波是从 2.12 跌下来的正常回调,大架子没坏;但现价买不划算——可能赚的还没可能亏的多,别追。已持有的继续拿,盯住 1.55,有效跌破再走;没买的等跌到 1.70~1.67 一带、成交量放出来再考虑。
【体检行】
大方向(周线):上涨中(多头),正在回调
位置:不高(已跌回近一年最便宜的区域)
劲头(动量):正常,没涨过头
买气(量能):注意·价涨量缩(反弹没量,动力存疑)
异常信号(背离):无
【结论分两行】新资金:不追,等 1.70~1.67 | 持仓者:持有观望,跌破 1.55 离场
【若下手】现价 R=0.68(<2,不合格);跌到 1.70 时 R≈2.4(合格);若此刻一定动手,仓位 ≤2% 市值
20 日后回填:走势____ 判定对否____
```

## 6. 参数与禁用项

- **标准参数**:RSI(14)、MACD(12,26,9)、BOLL(20,2)、ATR(14)。周期:**周线定中线,日线定进出**。
- **默认不使用**:KDJ(与 RSI 重复,仅 RSI 读数存疑时交叉验证)、布林带打分(仅布林上轨用于目标价规则)、ADX 精确阈值(肉眼周线均线斜率即可,拿不准时辅助)、估值分位(基本面指标,中线高位警惕时另查,不进盘中流程)。
