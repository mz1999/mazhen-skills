# Source Example Index

All 31 examples from [ThariqS/html-effectiveness](https://github.com/ThariqS/html-effectiveness) are mirrored locally under Apache-2.0. See [source provenance](examples/SOURCE.md) and the [license](examples/LICENSE).

Open only local examples selected for the current artifact. Study their information structure and interaction ideas; create the visual design for the current content rather than inheriting the example's styling. Online originals are reserved for user-requested source checks or updates.
